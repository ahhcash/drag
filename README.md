# dRAG - a RAG based chatbot for your doc!
![github actions](https://github.com/ahhcash/drag/actions/workflows/ci.yml/badge.svg)

end goal: you should be able to drop a (root) link to your docs, and drag will crawl through all your docs pages, index them and create a chatbot for your to ask questions.
you can have multiple chatbots for diffferent documentation.
